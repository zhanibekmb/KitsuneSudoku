# KitsuneSudoku 🦊 - Твой Утренний Фокус

Эстетичное и минималистичное веб-приложение для игры в Судоку, созданное, чтобы заменить утренний "думскроллинг" на полезную разминку для мозга. Плавные анимации, расслабляющий интерфейс и продуманная система прогрессии помогут вам начинать каждое утро с пользой.

## 🎯 Идея проекта
KitsuneSudoku — это больше, чем просто судоку. Это ваш инструмент для развития концентрации и логического мышления. Мы превратили классическую головоломку в увлекательный процесс с элементами геймификации, чтобы мотивировать вас возвращаться каждый день вместо бездумного пролистывания социальных сетей.

## ✨ Основной функционал

### 🎮 Игровой процесс
- **4 Уровня сложности**: От "Утренней разминки" (Easy) до "Мастер-класса" (Expert) для гуру логики. Доступ к более сложным уровням открывается по мере ваших побед.
- **Интеллектуальная клавиатура**: При полном заполнении одной цифры 9 раз на поле, её кнопка на панели становится полупрозрачной и отключается, визуально помогая фокусироваться на оставшихся числах.
- **Умная подсветка (Highlighting)**: Автоматическая подсветка всех одинаковых цифр на поле для быстрой навигации и чтения доски.
- **Система Заметок (Notes)**: Как бумажный черновик — возможность делать пометки потенциальных чисел в клетках.
- **История Ходов**: Функции отмены ходов (Undo) и стирания (Eraser).
- **Прогрессивная разблокировка уровней**: 
  - Medium открывается при 5 победах.
  - Hard открывается при 15 победах.
  - Expert открывается при 30 победах.

### 📈 Уникальная система очков и рейтингов
Для каждого режима разработана своя система начисления баллов. Чем быстрее вы решаете и чем меньше делаете ошибок, тем больше бонусных Points и Коинов получаете!

- **Easy**: Ожидаемое время решения — 5 минут. Максимальная награда: **100 Pts / 22 🟡**
- **Medium**: Ожидаемое время решения — 10 минут. Максимальная награда: **200 Pts / 45 🟡**
- **Hard**: Ожидаемое время решения — 20 минут. Максимальная награда: **400 Pts / 90 🟡**
- **Expert**: Ожидаемое время решения — 40 минут. Максимальная награда: **1000 Pts / 180 🟡**
- **Time Challenge (Секретный)**: Обратный отсчёт на 5 минут (чем больше минут осталось, тем выше награда). Максимальная награда: **900 Pts / 150 🟡**
- **Wordoku (Эксклюзив)**: Буквенная головоломка. Сложность увеличена. Максимальная награда: **600 Pts / 120 🟡**

> **Важно**: При победе без ошибок (0 Mistakes) вы получаете **х1.5 множитель** к заработанным Монетам!

### 💰 Внутриигровая Экономика и Награды
- **Внутриигровая валюта (Коины 🟡)**: Начисляется за успешное прохождение уровней. Монеты можно тратить в Магазине.
- **Магазин предметов (Item Shop)**:
  - ❄️ **Streak Freeze (Заморозка стрика)**: Спасает стрик, даже если вы пропустили день. (Нельзя иметь больше двух штук в инвентаре одновременно, чтобы не расслабляться!).
  - 👑 **Бронзовая и Золотая Корона (Бейджи)**: Выделяют ваш ник на лидерборде.
  - 🎓 **Гроссмейстер (Титул)**: Уникальная подпись под вашим именем.
  - ⚡ **Time Challenge (Секретный режим)**: Режим игры на время с жестким таймером на 5 минут за большую награду. Разблокируется за 500 🟡.

### 🏆 Социальные фичи
- **Защита Стрика (Автоматическая)**: Вам не нужно ничего нажимать! Если вы забыли поиграть сегодня, но в инвентаре была Заморозка Стрика, на следующий день вы просто увидите приветственное уведомление: Заморозка спасла ваш огонек! Если пропущено несколько дней, Заморозки сгорают соответственно количеству дней.
- **Ежедневный Стрик (Streak 🔥)**: Заходите каждый день, чтобы ваш стрик рос. Поддерживает мотивацию.
- **Глобальный и Локальный Лидерборды**: Соревнуйтесь по очкам с игроками со всего мира или переключитесь на ваш город, чтобы посмотреть локальный топ.
- **Локальное сохранение данных**: Игра автоматически запоминает ваш прогресс благодаря `localStorage` (Zustand). Когда вы вводите тот же никнейм и город, ваш профиль автоматически восстанавливается из локального кэша, сохраняя вашу PRO-подписку, статистику и коины.

### 🤖 AI Тренер (Gemini)
Встроенный интеллектуальный компаньон, который не просто дает вам правильный ответ, а выступает в роли сенсея:
- Анализирует текущее состояние доски через Google Gemini SDK.
- Дает направляющие подсказки.
- Обучает продвинутым техникам игры в судоку.

## 💎 Преимущества PRO-подписки

Подписка Pro выводит процесс на новый уровень, давая эксклюзивные инструменты и новые испытания для настоящих фанатов.

1. 🪄 **Авто-заметки (Auto Notes)**: 
   Надоело вручную проставлять кандидатов во все ячейки в начале сложной игры? Одно нажатие — и AI автоматически расставит корректные карандашные пометки. *Баланс:* за использование этой ультимативной фичи к вашему таймеру добавляется 3 штрафные минуты.
   
2. 🔠 **Эксклюзивный режим "Wordoku"**:
   Смените фокус с цифр на буквы! Специальный режим только для Pro-пользователей. Играйте латинскими буквами от A до I вместо цифр от 1 до 9. Отлично ломает устоявшиеся паттерны мышления.
   
3. ♾️ **Безлимитные AI-подсказки**:
   Обычные пользователи имеют ограниченный пул AI-разборов ваших ходов. С Pro-подпиской ваш AI-наставник всегда рядом без ограничений.

4. 👑 **Отображение Pro статуса**:
   Специальный бейдж Pro-пользователя (Sparkles) в вашем профиле и на лидерборде.

## 🛠 Технологии под капотом

- **React + Vite** для быстрой сборки и мгновенного отображения.
- **Tailwind CSS + shadcn/ui** для эстетичного, минималистичного и отзывчивого UI.
- **Zustand** для стейт-менеджмента.
- **Google Gemini SDK** в качестве AI-тренера.
- **Lucide React** для иконок.

## 🚀 Как запустить проект локально

Убедитесь, что у вас установлен Node.js.

1. Клонируйте репозиторий:
   ```bash
   git clone <URL вашего репозитория>
   cd <название папки>
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Настройте ключи API:
   - Скопируйте `.env.example` в `.env`: `cp .env.example .env`
   - Вставьте ваш `GEMINI_API_KEY` в файл `.env`, чтобы заработали подсказки AI-Коуча.
4. Запустите в режиме разработки:
   ```bash
   npm run dev
   ```
5. Откройте `http://localhost:3000` в вашем браузере.

Для сборки проекта в production выполните команду:
```bash
npm run build
```
Готовые статические файлы будут лежать в папке `dist/`, которые можно будет легко задеплоить на любой удобный хостинг.
